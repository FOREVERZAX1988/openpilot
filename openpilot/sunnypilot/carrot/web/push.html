当前是 App 内置浏览器

微信 / QQ / 抖音 / 小红书等内置浏览器不支持 Web Push，通知权限会直接返回 denied，也没有「添加到主屏幕」。请点右上角「…」→ 用浏览器打开（Chrome / Safari），或复制链接到浏览器。

通知权限已被"拒绝"，浏览器不会再弹窗

改完设置后回到本页点「重新检查」。如果这是 cloudflared 临时隧道，域名每次重启都会变（每次都是新站点），务必用同一个域名完成设置。

iPhone / iPad 需要手动添加

  1. 用 Safari 打开本页
  2. 点底部「分享」→「添加到主屏幕」
  3. 从主屏幕图标进入（才会 standalone），再点「开启通知」
